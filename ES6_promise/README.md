# ES6 Promises

This project is part of the JavaScript curriculum at Holberton School. It focuses on asynchronous programming concepts in JavaScript (ES6), specifically working with **Promises**, `async/await`, error handling, and promise resolution/rejection methods.

## 🛠️ Setup & Installation

### 1. Install Node.js 20
If Node.js is not installed on your system, run the following commands in your terminal:

```bash
curl -sL [https://deb.nodesource.com/setup_20.x](https://deb.nodesource.com/setup_20.x) -o nodesource_setup.sh
sudo bash nodesource_setup.sh
sudo apt install nodejs -y
